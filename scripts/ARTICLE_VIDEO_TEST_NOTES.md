# Article video resolver checks

`node scripts/test-article-video.cjs` exercises the actual helper and API with the installed sanitize-html parser and deterministic DNS/HTTPS streams. Sixty-four scenarios verify auth before JSON/network, syntax/length boundaries, signed query and one-time entity decoding, relative/base/redirect resolution, raw/comment/inert/embedded false sources, public-only literals and all DNS results, pinned IPv4/IPv6 sockets, private media skipping, redirect bounds, HTML type/byte limits, interrupted responses and shared DNS/header/body/candidate deadlines. No video is downloaded and no production records are written. Mocked socket results prove request construction and failure handling; the coordinating task separately verifies the live article and actual form.
