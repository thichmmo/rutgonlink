# Admin daily popup click UI checks

`node scripts/test-admin-popup-clicks-ui.cjs` mounts the actual admin user list/detail using React/JSDOM and mocked read APIs. List checks distinguish each user's total/Shopee/TikTok counts, real zero versus unavailable statistics, lifetime short-link clicks, the Vietnam snapshot date from a non-Vietnam browser timezone, manual refresh, all filters, pagination, detail navigation and API/permission errors. Reordered filter/page/refresh responses, delayed JSON, stale errors/loading completion and unmount are exercised explicitly. Detail checks retain action drafts on manual refresh, reset them on route-ID navigation, and reject delayed body/refresh/errors from the previous account. These checks do not write production analytics or prove native app launches; the metric is accepted popup click events.
